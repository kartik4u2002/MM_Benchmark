# Benchmark Results and Artifacts

This directory stores experimental results, serialization files, and visualization charts generated by the benchmarking framework.

## Structure

- `benchmark_results.csv`: Unified benchmark measurements for small, medium, large, rectangular, and prime matrix shapes, recording median/mean latency, GFLOP/s, speedup, and numerical tolerance checks.
- `BENCHMARK_ANALYSIS.md`: Generated markdown report with formatted performance tables, cache hierarchy analysis, and correctness verification summary.
- `pytorch_inference_results.json` & `pytorch_inference_results.csv`: PyTorch CPU inference benchmark outputs evaluating batch latency and throughput.
- `plots/`: High-resolution figures generated by `python/plot_results.py`:
  - `throughput_comparison.png`: Throughput (GFLOP/s) across optimization levels.
  - `tile_size_sweep.png`: Cache blocking throughput curve across tile dimensions.
  - `speedup_summary.png`: Speedup factors relative to baseline.
- `raw/`: Intermediate per-configuration JSON and CSV outputs.
